# Doom for ArcOS

This package ports 1993 Doom to ArcOS v7 by using JS-DOS. This also means that it's running in a fully fledged DOS virtual machine, emulated in the browser, which in my opinion is already cause for celebration.

## Known problems

- There currently isn't any kind of load/save capability implemented, because the JS-DOS API is a very untamed creature I don't fully understand.
